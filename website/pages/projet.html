LE PROJET

Faire durer l’information.
Faciliter la transmission.

Domolyma construit un dossier de vie commun pour les biens et les personnes qui les font vivre.

La copropriété
comme point de départ.

Un immeuble traverse les années. Ses informations aussi.

Les personnes changent, les contrats évoluent, les travaux se succèdent. Le projet vise à relier les dossiers pour retrouver les décisions et poursuivre les actions sans repartir de zéro.

La gestion de copropriété est prioritaire. Le dossier locatif et la vision de plusieurs biens prolongent cette base.
